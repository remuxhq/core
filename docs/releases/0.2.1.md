remux 0.2.1.

- Filters are ports: the domain owns the contracts (`ShaderCompiler` for WGSL, `Filter` and `MakeGate` for the gate), the adapters (`remux-shader`, `remux-mixer`) depend on the domain, and the daemon's `main.rs` injects them into the motor. `make remuxd.seam` fails if the domain or the CLI reaches an adapter.
- A release publishes itself: merging the pull request that moves the version runs `release.yml`, which tags and publishes it unless it is already released.
- Nothing changes for a person using remux.
