remux 0.2.0.

- The picture is layers in named scenes: screens, windows, cameras, text and timers in one back-to-front order, and `remux scene switch` changes the whole picture at once. The fixed layout and the cards are gone.
- The commands are grouped: scene, audio, music, destination and chat. Scripts written for 0.1 need the new words; `remux guide` has them all.
- Filters are WGSL files, on one layer or on the whole scene: `remux scene layer filter <id> <file.wgsl>` and `remux scene filter <file.wgsl>`.
- `remux devices` no longer opens the microphone to list it, so a Bluetooth headset keeps its sound while you look.
- Going live with an empty scene is refused, as the plan already said; an empty music folder says where tracks go and where to find free ones.
- For developers: macOS needs `brew install simde`, Linux `libobs-dev`, to build the libobs bindings.
